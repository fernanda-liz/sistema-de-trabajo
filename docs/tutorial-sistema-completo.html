🚀 Sistema Integrado: Obsidian + Zotero + IAs + Triaje

Manual interactivo para Valeska — Replicate el flujo de trabajo con cualquier IA

🎯 Introducción: ¿Qué es este sistema?

Este manual te enseña a:

  1. Capturar sin clasificar en Obsidian (notas, tareas, ideas)
  2. Triaje automático: Una IA distribuye todo a kanbans personales (por proyecto, tema, ámbito)
  3. Zotero integrado: Referencias académicas automáticas en formato APA 7
  4. Cualquier IA: Claude Code, Codex, Antigravity u OpenClaw — elige una o varias
  5. Segundo cerebro: Que sobreviva a cambios de equipo, SO o herramienta
⏱️ Tiempo total: 30-40 minutos desde cero hasta funcionando

📋 Diagrama del flujo completo

┌─────────────────────────────────────┐ │ 1️⃣ CAPTURA (Obsidian) │ │ Escribe en inbox.md sin clasificar │ │ (iPhone, iPad, Mac — iCloud sync) │ └────────────┬────────────────────────┘ │ ↓ ┌─────────────────────────────────────┐ │ 2️⃣ TRIAJE (Tu IA elige) │ │ • Ámbito (Trabajo, Tesis, etc) │ │ • Tema (Proyecto A, Entrega B) │ │ • Fecha objetivo │ └────────────┬────────────────────────┘ │ ↓ ┌─────────────────────────────────────┐ │ 3️⃣ KANBAN PERSONAL │ │ Backlog → En curso → Bloqueado │ │ (Tu diseñas la estructura) │ └────────────┬────────────────────────┘ │ ↓ ┌─────────────────────────────────────┐ │ 4️⃣ ZOTERO (Referencias APA 7) │ │ IA agrega PDFs automáticamente │ └──────────────────────────────────────┘

🔧 Paso 1: Instala Node.js (Necesario para todas las IAs)

Mac (con Homebrew):
brew install node
Windows: Descarga desde nodejs.org (versión LTS 22+)
Linux:
sudo apt install nodejs npm # Debian/Ubuntu sudo dnf install nodejs npm # Fedora sudo pacman -S nodejs npm # Arch
Verifica: node --version y npm --version deben mostrar números

🤖 Paso 2: Elige tu IA (o varias)

Claude Code (Anthropic)

Instalación

npm install -g @anthropic-ai/claude-code claude --version

Primer uso: Al ejecutar claude, logueate con tu cuenta de Anthropic (plan gratis o pago)

✅ Ventajas

  • Mejor comprensión de contexto (lee CLAUDE.md automáticamente)
  • Excelente para análisis complejos
  • Soporte nativo de MCP (Model Context Protocol)

⚠️ Consideraciones

  • Requiere cuenta de Anthropic
  • Costo según uso (plan gratis tiene límites)

Codex CLI (OpenAI)

Instalación

npm install -g @openai/codex codex --version

Primer uso: Necesitas una API key de OpenAI (genera en platform.openai.com) o autenticar con tu cuenta ChatGPT

✅ Ventajas

  • Excelente para código y scripting
  • Compatible con macOS, Windows, Linux
  • Modelos rápidos y económicos

⚠️ Consideraciones

  • API key debe guardarse en archivo .env (nunca en Git público)
  • Costo variable según tokens usados

Antigravity (Google)

Instalación

  1. Baja desde antigravity.google/download
  2. Instala el ejecutable para tu SO (macOS, Windows, Linux)
  3. Logueate con tu cuenta de Gmail personal

Nota: Antigravity es un IDE completo, no solo CLI. Más que las otras opciones.

✅ Ventajas

  • IDE visual integrado
  • Acceso a herramientas Google (Drive, Sheets, Docs)
  • Debugging avanzado

⚠️ Consideraciones

  • Mayor consumo de recursos
  • Requiere cuenta de Gmail personal (no workspace corporativa)

OpenClaw (IA China)

Instalación

npm install -g @openclaw/cli openclaw --version

Primer uso: Crea cuenta en platform.openclaw.ai y genera API key

✅ Ventajas

  • Modelos optimizados para chino y multihabilidad
  • Costos muy competitivos
  • Buena compatibilidad con estándares OpenAI

⚠️ Consideraciones

  • Latencia (servidores en China)
  • Documentación principalmente en chino
  • API key debe estar en .env (seguro)

📁 Paso 3: Crea tu primer "Cofre"

Un cofre es simplemente una carpeta con estructura mínima:

mkdir mi-cofre cd mi-cofre git init echo "# Mi Cofre" > README.md echo "# Reglas del proyecto" > CLAUDE.md echo "# Notas internas" > notas.md
CLAUDE.md (o AGENTS.md): Escribe las reglas de tu proyecto:
  • ¿Qué va en este cofre?
  • ¿Qué se excluye?
  • Estructura de carpetas
  • Convenciones (nombrado de archivos, format)
notas.md: Bitácora append-only con entradas fechadas. Nunca se reescribe, solo se agrega.
## [2026-09-11] Primer cofre creado Descripción de qué estoy haciendo ## [2026-09-12] Integración Zotero completada Lo que cambió hoy

🗂️ Paso 4: Obsidian — Captura sin clasificar

Descarga Obsidian: obsidian.md (gratis, app local)

Estructura recomendada:
mi-cofre/ ├── CLAUDE.md ├── notas.md ├── captura/ │ └── inbox.md ← Todo entra aquí, sin clasificar ├── kanban/ │ └── trabajo.md ← Tu kanban personal (diseñado por ti) └── wiki/ └── index.md ← Índice de artículos/páginas
inbox.md — Formato:
# Inbox Nuevas entradas van AL INICIO, separadas por --- ## [NUEVAS ENTRADAS - ESCRIBE AQUÍ] Entrada 1 (la más nueva) Entrada 2 --- ## 2026-09-10 (✅ TRIADO) Entrada triada anterior ---

🎯 Paso 5: Sistema de Triaje (Lo mágico)

Una vez escribes en inbox.md, tu IA:

  1. Lee lo nuevo (desde el primer --- hacia abajo)
  2. Identifica: Ámbito (Trabajo, Tesis, Diseño), Tema (Proyecto X), Fecha objetivo
  3. Crea tarea en tu kanban personal con formato:
- [ ] Título claro con verbo #tema/subtema 📅 2026-09-15 (2h/día)
  1. Archiva la entrada en inbox-archive-YYYY-MM-DD.md
  2. Limpia el inbox y lo deja listo para nuevas entradas
Regla de oro: Nunca borres nada. Siempre archiva con fecha. El historial es tu memoria.

📚 Paso 6: Zotero — Referencias automáticas APA 7

Instala Zotero: zotero.org (gratis, 300MB; pago para más)

Configuración básica:
  1. Abre Zotero y crea una biblioteca (o usa la por defecto)
  2. En tu IA, conecta Zotero vía MCP (Model Context Protocol)
  3. La IA puede ahora buscar artículos, descargar PDFs y agregarlos automáticamente
Flujo ejemplo:
Usuario en inbox: "Necesito artículo sobre impresión 3D y composites" ↓ IA triaja: "Buscar referencias → Agregar a Zotero → Crear página wiki con citas APA 7" ↓ Resultado: Zotero tiene 5 nuevos artículos + wiki actualizada
